========================================
  SECRELY — INSTALL BEFORE RUNNING
========================================

-----------------------------------------
NODE.JS VERSION REQUIREMENT
-----------------------------------------

Required: Node.js 18.17.0 or later
Recommended: Node.js 20.x LTS

Check your version:
  node --version

If you need to upgrade:
  https://nodejs.org/en/download
  (or use nvm: nvm install 20 && nvm use 20)


-----------------------------------------
PACKAGE MANAGER
-----------------------------------------

This project uses npm (comes with Node.js).
Yarn and pnpm also work but are not required.

npm --version   # Should be 9.x or later


-----------------------------------------
INSTALLATION STEPS (in order)
-----------------------------------------

Step 1: Navigate to the project folder
  cd secrely

Step 2: Install all dependencies
  npm install

  This installs everything listed in package.json including:
  - Next.js 14
  - React 18
  - TypeScript 5
  - Tailwind CSS 3
  - Motion (Framer Motion v11)
  - Zustand 4
  - Lucide React
  - All @radix-ui/* primitives
  - clsx, tailwind-merge, class-variance-authority
  - date-fns

Step 3: Start the development server
  npm run dev

Step 4: Open in browser
  http://localhost:3000


-----------------------------------------

  ✗ No .env file needed

-----------------------------------------
COMMON ERRORS & FIXES
-----------------------------------------

ERROR: "Cannot find module 'motion/react'"
FIX:   npm install motion
       (Motion v11 exports from 'motion/react', not 'framer-motion')

ERROR: "Cannot find module '@radix-ui/react-dialog'"
FIX:   npm install (run again — dependency may have failed)

ERROR: "SyntaxError: Cannot use import statement"
FIX:   You are on Node.js < 18. Upgrade to Node 18+.

ERROR: Port 3000 already in use
FIX:   npm run dev -- -p 3001
       (or kill the process using port 3000)

ERROR: Build fails with TypeScript errors
FIX:   npm run lint to see issues
       These are type errors — check paths and imports

ERROR: Fonts not loading
FIX:   The app loads Google Fonts from the internet.
       Ensure you have an internet connection on first load.
       After first load, fonts are cached by the browser.

ERROR: Images not showing (blank squares)
FIX:   Images use Unsplash URLs configured in next.config.js.
       Ensure you have an internet connection.
       If blocked, replace with local images in /public/


-----------------------------------------
TAILWIND CSS SETUP
-----------------------------------------

Tailwind is pre-configured. No manual setup needed.

Files already configured:
  - tailwind.config.ts  (content paths, custom tokens)
  - postcss.config.js   (tailwindcss + autoprefixer)
  - src/app/globals.css (CSS variables + base styles)

Do NOT run: npx tailwindcss init (already done)


-----------------------------------------
RADIX UI / COMPONENT SETUP
-----------------------------------------

This project does NOT use the shadcn/ui CLI.
All UI components are hand-written in src/components/ui/
and are built on @radix-ui/* primitives.

Do NOT run: npx shadcn-ui init
Do NOT run: npx shadcn-ui add [component]

All Radix packages are installed via npm install from package.json.


-----------------------------------------
GOOGLE FONTS
-----------------------------------------

Fonts (DM Sans + Playfair Display) are loaded via:
  src/app/globals.css @import

This requires an internet connection on first load.
No local font files or next/font setup required.


-----------------------------------------
FULL CLEAN INSTALL (if things go wrong)
-----------------------------------------

  rm -rf node_modules .next
  npm install
  npm run dev


-----------------------------------------
PRODUCTION BUILD CHECK
-----------------------------------------

  npm run build   # Must complete with no errors
  npm run start   # Serves built app at localhost:3000


-----------------------------------------
QUICK START (one-liner)
-----------------------------------------

  cd secrely && npm install && npm run dev
